# Destination B — four-block NB2 conditional-replication diagnostic

Status: one fixed information diagnostic for the partial all-four-source NB2
receipt. It is not a re-run-until-pass exercise, a replacement for the original
96-observation failure, or a recovery/coverage result.

## Immutable base model

This diagnostic reproduces exactly the original NB2 fixture from
`test_destination_b_joint_other_families.jl`: `StableRNG(202609078)`, two
traits, 12 units × 8 observations, 48 globally nested and twice-replicated
`unit_obs` levels, eight crossed `cluster` levels, eleven crossed `cluster2`
levels, means `(0.70,1.00)`, source SDs `(0.38,0.30,0.24,0.20)`, trait sizes
`(1.5,2.5)`, and four `:indep, common=true` terms. The source-effect matrices
and first conditional response block are generated by the same direct code;
the first `2×96` response prefix has fixed SHA-256 hash
`5035068e1990ae61f4e43fef410837d450ab78aaad6fc0f80f371332880fe8f0` over
`join(vec(Y), ",")`.

For the original latent predictors `eta[t,i]`, append three blocks by
continuing the same RNG after the first response draws:

```math
Y_{t,i+96b} \mid \eta_{ti} \sim
  \operatorname{NB2}\left(r_t,\;r_t/(r_t+\exp(\eta_{ti}))\right),
\quad b=1,2,3.
```

Thus the first block is retained verbatim and the next three are independent
conditional response draws at the *same* latent predictors and group labels.
The 384-row label vectors repeat the original labels in block order: each
`unit_obs` level is replicated eight times rather than two, while every source
level, effect, truth, seed, response model, and fitter control is unchanged.

| Symbol | unchanged DGP / fitted term | replication action | check |
| --- | --- | --- | --- |
| `U,O,C,D` | original independent source draws / four `:indep, common=true` terms | none; reuse the exact draws and labels | fitted covariance components stay finite and diagonal |
| `Y` block 1 | original direct NB2 response draw | frozen exact prefix and hash | equality plus hash gate |
| `Y` blocks 2–4 | same NB2 conditional distribution | three new sequential RNG draws at same `eta` | information increase only |
| `r_1,r_2` | `(1.5,2.5)` trait-specific NB2 size | none | both named size intervals inspected |

## Predeclared one-fit gate

Fit the n=384 response once through public `fit_gllvm` with the original
family marker, four terms, `iterations=250`, and `g_tol=1e-4`, then call
`grouped_nongaussian_intervals` on the retained response and repeated labels.
The initial criterion is finite converged/PD/`:ok` output and available source
variance intervals for all four terms plus both size intervals. It has a local
two-minute stop limit in `/private/tmp/destination-b-quality-g8dtHV`.

If that criterion is not met, retain its first partial or invalid pattern with
the prefix gate and all controls unchanged. StableRNGs absence is an explicit
Broken skip, never evidence of this fitted diagnostic.

## First enlarged-fit receipt

The first n=384 fit passed 61/61 assertions in 10.6481 seconds of fit-plus-
interval time (16.3 seconds fresh-process wall time). Its first 96 responses
matched the frozen hash and all repeated labels retained the original block
ordering. The public fit was converged, positive-curvature, and inner `:ok`;
all four extracted covariance components were finite, positive, and diagonal.
The marginal interval result was `:available`, including both trait variance
targets for every source and both NB2 size targets.

The contrast with the original n=96 partial receipt supports only the narrow
information diagnosis: under this fixed latent-effect realization, increasing
conditional-response replication from two to eight per `unit_obs` level made
the four source variance intervals feasible. It does not alter the original
receipt, establish estimator recovery or interval coverage, or show that this
will occur for other seeds, effects, incidence patterns, or covariance modes.
