## Hopper pin (do not re-derive)

Twin `.aghq_gate` in `R/aghq-gate.R` (@ `b926f47f`) measures TMB `spHess`
sparsity, then min-fill treewidth. `tw ≤ 4` proceeds to quadrature; else
the twin **warns and falls back to Laplace**. That fallback is honest
because the twin already ships a public `aghq=` control. **Do not port**
the TMB Hessian / min-fill / `.aghq_gate` path. Julia AGHQ is a dense
per-site `d × d` loadings-only `z_B` block — the wrong substrate for a
graph algorithm.

Julia `_aghq_stage1a_reject_extra` in `src/families/aghq_grid.jl`

advertise a quadrature path the package does not expose.

Optional cheap analogue, not a graph algorithm: a complete graph on `d`
nodes has treewidth `d − 1`, so the twin's `tw ≤ 4` cut is `d ≤ 5` on
this dense loadings-only block. A later test or tiny internal helper may
bound tensor cost `k^d` (or `d ≤ 5`) without importing min-fill or
`spHess`. That bound is optional. It is not `.aghq_gate`.

Name the TMB hard-exclusions the Julia site function does **not** carry:
REML `b_fix`, `equalto()`, `propto()`, multi-kernel. Those are twin
fitter / formula exclusions. Do not invent Julia counterparts in this
slice, and do not treat their absence as a porting debt for A4(3).

## Decision

### Fail-loud `_aghq_stage1a_reject_extra` is the A4(3) eligibility gate

The helper rejects **declared** extras (`phylo=true`, `row_effects=true`,
`mi=true`, free `s_B` / `unique_latent=true`, `use_lv_B=true`,
multinomial). It does **not** inspect the model and reject anything that
is not a loadings-only `z_B` block. Defaults are `nothing`; omitted
kwargs never fire the gate. Detection remains the **caller's** until a
fitter wires the flags. Opus MIXED review of #253 recorded the
omitted-kwargs probe: an ineligible model called without those kwargs
returned a finite number (`-9.156783`; no gate fired). Blast radius is
zero today — nothing public calls the site evaluator. Keep throwing on
declared extras. Do not soften those errors into a warn+Laplace path
until a public `aghq=` exists and A4(5) can label what was used.

`false` is inconsistent on the declared-kwargs surface and is **not**
fixed in this honesty slice (later engine, with omitted-kwargs
detection): `row_effects=false` / `phylo=false` / `mi=false` throw;
`unique_latent=false` / `use_lv_B=false` / `multinomial=false` pass.

### Why Julia throws and the twin warns

| Surface | Ineligible model |
|---|---|
| Twin `.aghq_gate` | warn + Laplace — public `aghq=` already exists |
| Julia `_aghq_stage1a_reject_extra` | **throw** — no public knob; Identity §A3 forbids a stub |

Porting the twin's warn+Laplace behaviour before a public knob would hide
ineligibility inside the default Laplace fit. That is the EVA-honesty
failure Identity already rejected.

### Optional `k^d` / `d ≤ 5` bound is not treewidth

If a later test names a cost bound, state it as tensor size or latent
dimension on dense loadings-only `z_B`. Do not claim a treewidth
measurement. Do not add a graph library. Do not call the helper
`.aghq_gate`. The `#253` absence tests (`!isdefined` of
`_aghq_kd_bound` / `_aghq_d_bound` / `aghq_gate`) record that this
slice did **not** invent the helper. They do **not** close
affordability. Delete those absence tests when the affordability half
ships. This paragraph does **not** close the affordability half.

### A4(4) is not closed

Julia Stage-1b already re-solves the Laplace mode and Cholesky at every
site evaluation (`aghq_stage1a_loglik_site`). The twin's `DATA_` freeze /
`n_adapt` / continuation / F-versus-surrogate loop is a **fitter**
problem. A canned "adaptation loop kernel" would invent a TMB freeze
Julia does not have. Why-not lives here so a later lane does not pad
A4(4) as engine work. This paragraph does **not** close A4(4).

### A4(5) is not closed

Report honesty is a field list (`used`, `k`, engine label) so print / AIC
cannot mix Laplace and AGHQ silently. A4(5) needs a public fitted-object
surface. Identity §A3 still forbids a stub `aghq=` that only errors.
Listing the fields is not shipping them. This paragraph does **not**
close A4(5).
