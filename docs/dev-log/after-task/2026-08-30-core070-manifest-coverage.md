# Source coverage must precede contract freeze

## 1. Goal
Prevent a status-only freeze from bypassing the source-to-executable-case work required by the approved programme.

## 2. Implemented
Added source-fact index and explicit unmapped case ledger; frozen source and namespace checks; declaration-only R parser; source coverage and pinned scope-review requirements in the public loader. Existing receipt collection tests now explicitly isolate transport metadata rather than imply full semantic coverage.

## 3a. Decisions and Rejected Alternatives
Do not mark the manifest frozen.752 source facts overlap and are not a capability or fit count.698 non-excluded facts require executable links; independent semantic source review remains unpaid. Retain ambiguous data utilities for review rather than silently excluding them. A hashed review record is not proof that a review was actually independent; real review evidence is required.

## 4. Files Touched
Coverage index/map, parser/checker/tests, aggregate loader and transport-test seam; required-case coverage note, check-log and LOOP. No numerical engine, frozen R source, fixture or tolerance edits.

## 5. Checks Run
Initial relabeled-draft regression failed because the loader accepted it. After repair24 tests pass:6 coverage,9 collection,4 assertion grouping,5 process evidence; aggregate self-test passes. Current752-row source index matches pinned inputs and namespace declarations. Earlier six-binomial qualification verifier still passes. No fits or remote campaigns.

## 6. Tests of the Tests
Coverage mutations omit/duplicate a fact, erase a case, invent a case, alter classification, erase rationale, orphan a case, change reference and malform rows. Pinned-review fixture rejects changed mapping/review hashes, omitted domains and altered review evidence. Escaping paths and absent review bindings fail. Full real draft relabeledFROZEN still fails the production loader.

## 7a. Issue Ledger
Freeze-loader gap repaired. Full executable map is still incomplete:698 non-excluded source facts lack links; source facts overlap. Semantic completeness beyond known inventories and independent review remain unpaid. No capability has been promoted.

## 8. Consistency Audit
Namespace IDs are checked against exact frozen declaration lines, not only counts. Source classifications remain visible beside normalized programme classes. DRAFT status and existing numerical evidence remain intact. Public verifier entrypoints require coverage; synthetic transport-only tests do not claim source completeness.

## 9. What Did Not Go Smoothly
The acceptance leaf was written after the first red regression and initial repair, a process miss recorded explicitly. Final reviewed checks were then run freshly. The known source index cannot establish that every semantic branch has been discovered, so an exhaustive-scope claim is withheld.

## 10. Known Residuals
The ledger is a prerequisite, not a substitute for executable models, actual fits, recovery, interface coverage, AGHQ or independent review. No full package tests or Documenter build were run for this local metadata/validator slice.

## 11. Team Learning
A complete receipt for a declared list does not prove the list covers the source contract. Bind the source-to-case map before accepting a frozen label, and keep mechanical checks separate from semantic review.
