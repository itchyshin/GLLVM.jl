# Gaussian covariance formula qualification

## 1. Goal
Qualify the wide and reversed-long Julia formula routes for the same nine
Gaussian covariance models already required in the native/R contract. Keep
remaining bridge, non-Gaussian and programme requirements visible.

## 2. Implemented
Nine formula-interface IDs join the central required runner. Each requires its
native comparison in the same process. Two immutable groups exercise two fixed
ordinary models and seven ordinary/animal/kernel models. The helper reuses their
actual R/native fits and data, retains every attempted formula fit, and writes
progress before asserting. A separate verifier checks raw R objects, exact native
bindings, formula outputs and a base-Python normalized Gaussian density.

## 3a. Decisions and Rejected Alternatives
No R syntax imitation, new public API or numerical engine change. Formulas use
`gllvm(@formula(y~1), ...; sources=...)` with wide input or reversed trait/unit
long input. Fixed residual models retain the exact R fixed value. Ordinary DEP
compares total covariance only; source and residual are not separately identified.
The six structured models use the same input_C+1e-8I as the native fixture. The
R inverse-precision reconstruction has roundoff and is checked as evidence, not
passed as an exactly symmetric constructor input. No new ridge/tolerance policy.
