### A — Finish the M2 remainder only

**Meaning:** take the bounded, leave-able M2 continuation in #303: local EOO
smokes and the remaining M2-S1 receipt/`se=TRUE` harness work, with diagnostic
receipts and a handoff.

and file ownership. This is the only option whose size is measured in days.

promotion, a Totoro relaunch, or an M5 claim.

**Best when:** the immediate goal is to close the current M2 evidence loop while
preserving the larger programme for a later decision.

### B — Pursue `v0.true-parity` against frozen 0.7.0

**Meaning:** use #291 as the canonical programme, beginning with the selected
post-G0 build arc and eventually qualifying the signed 42-row tier against the
frozen 0.7.0 oracle. “Complete” means retained paired evidence for the
owner-approved rows at their required tiers; it does not mean every ledger row
is covered.

**Honest effort:** approximately **120–230 agent-days** over **9–18 calendar
months**, with several separately approved arcs. This is a programme, not a
single `/goal` and not an automatic authorization to execute every row.

**Best when:** the intended outcome is a durable, auditable Julia↔R
qualification milestone rather than a release-version match.

### C — Promote the gllvmTMB 0.7.1 Class-1 catch-up

**Meaning:** select named 0.7.1 Class-1 rows (`traits()`, `*_coef`,
`*_slope`, or others) as a separate catch-up destination. It must not silently
change B’s frozen oracle or 42-row gate tier.

**Honest effort:** **not yet estimable as one number**. A narrow named-row
catch-up may be measured in weeks; the whole Class-1 surface is a separate
catch-up programme and must not inherit the 120–230 agent-day B estimate
without an inventory and dependency map. The first deliverable after G0 would
be the named-row inventory and acceptance map, not a broad port.

**Best when:** the immediate priority is user-visible 0.7.1 API compatibility
and Shinichi is willing to maintain a parallel compatibility ledger.

### D — Name another destination

**Meaning:** Shinichi may choose a different end state, but it must be stated as
an end state rather than an activity. It must name the R reference, included
surface, acceptance rows, explicit exclusions, and the point at which the
claim is allowed.

**Honest effort:** **unknown until those four fields are supplied**. The plan
will not invent a number or pretend that a generic “all the way” route is
specified.

**Best when:** A–C do not capture the actual scientific or product objective.
