## Numerical acceptance

Phylo: reproduce original Gate 3 and trace optimizer trials into precision
assembly. Distinguish invalid/non-finite parameters, conditioning and mathematical
indefiniteness. No blind ridge enlargement. Stabilization requires a reviewed
scale-aware rule and visible diagnostic; invalid trials cannot become good fits.

Tweedie: fixed-common, shared-estimated, and per-trait-estimated power are distinct
models/tests; declare phi grouping, curvature, masks and normalization. Fixed
power controls cannot replace R-default per-trait estimation evidence.

Student: retain the ORIGINAL required fixture and absolute log-likelihood delta
<=1e-3, with both-engine health. Add interior/boundary diagnosis; cross-evaluation
does not substitute for a passing target receipt.

AGHQ: one ordinary loadings-only block, unique=false, no other random block,
X_lv, mi, or multinomial. Default off, positive k or auto; k=1 is Laplace.
Auto follows reference affordability/trait-count policy. Ineligible requests
retain Laplace with explicit warning/reason; invalid controls fail; no auto ridge.
Before code freeze outer adaptation/optimization, differentiated quantity, mode
dependence, convergence. Test normalization, moments, k=1, direct quadrature,
node refinement and outer derivatives. Report requested/actual method, k,
stopping reason and convergence. Gate helper breadth is NOT callable support.

All admitted routes freeze identification, shapes, native/formula/bridge reach,
inference and negative cases. Use covariance/prediction invariants for rotational
ambiguity. Recovery retains every attempt and predeclares estimands/alignment,
fit-health and acceptance; coverage must detect over- and under-coverage.
Timing freezes models/commits/threads; separates compile/warm/bridge; no
success-only filtering or blanket speed multiplier.
