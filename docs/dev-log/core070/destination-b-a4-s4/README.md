# A4/S4 closed Gaussian evidence matrix

This directory is reserved for immutable raw bridge attempts, separately
fenced private kernel checks, and any future reviewed paired-evidence
receipts.  It intentionally contains no successful paired-evidence receipt
yet.  The retained private `bridge_fit` transport uses its own raw schema; the
verifier recognizes it as raw, candidate-only evidence and never opens public
formula admission.

`raw-frozen-r-02.rds` is the current separate R-only declared-coordinate
material from a fresh, marker-attested 0.7.0 build.  Its point-only
construction explicitly requests `se = FALSE` and rejects any retained
`sd_report`; it retains two identical frozen-R marginal-objective calls for
each tree, pedigree, and dense row, plus the build/installed-tree provenance.
It contains no Julia evaluation, objective delta, own-optimum comparison,
interval calculation, or admission result, so it is not paired evidence and
cannot qualify an A4/S4 row.

`fixed-coordinate-kernel-cross-evaluation-02.json` is a later, private
kernel check built from that raw RDS through the RDS-to-JSON summary adapter.
It retains the raw-RDS SHA-256, fresh R build/DLL provenance, the fixed R and
Julia coordinate order, and the actual SHA-256 values bound for each retained
fixture, reference, precision source, and decoded response.  At the one
declared point the NLL differences (`Julia - R`) are `0`,
`7.1054273576010019e-15`, and `5.3290705182007514e-15` for tree, pedigree,
and dense respectively.  The record also carries runner source hashes marked
`runner_recorded_unverified`.

This is a private direct call to the Julia multivariate precision kernel.  It
is not a `bridge_fit` return, a public formula result, paired-evidence receipt,
independently fitted comparison, interval result, recovery result, or
admission decision.  Every row remains `qualified = false` and
admission-closed.

`raw-frozen-r-01.rds` is retained as the pre-correction raw receipt.  It
predates the explicit point-only `se = FALSE` control and must not be used as
the current raw-evidence artifact.  It remains unqualified and
admission-closed.

Dense VCV uncertainty is currently unavailable.  Do not fill this directory
with synthetic dense intervals.
