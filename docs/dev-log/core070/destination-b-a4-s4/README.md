# A4/S4 closed Gaussian evidence matrix

This directory is reserved for immutable future raw bridge attempts and their
reviewed paired-evidence receipts.  It intentionally contains no successful
paired-evidence receipt yet.  The retained private `bridge_fit` transport uses
its own raw schema; the verifier recognizes it as raw, candidate-only evidence
and never opens public formula admission.

`raw-frozen-r-02.rds` is the current separate R-only declared-coordinate
material from a fresh, marker-attested 0.7.0 build.  Its point-only
construction explicitly requests `se = FALSE` and rejects any retained
`sd_report`; it retains two identical frozen-R marginal-objective calls for
each tree, pedigree, and dense row, plus the build/installed-tree provenance.
It contains no Julia evaluation, objective delta, own-optimum comparison,
interval calculation, or admission result, so it is not paired evidence and
cannot qualify an A4/S4 row.

`raw-frozen-r-01.rds` is retained as the pre-correction raw receipt.  It
predates the explicit point-only `se = FALSE` control and must not be used as
the current raw-evidence artifact.  It remains unqualified and
admission-closed.

Dense VCV uncertainty is currently unavailable.  Do not fill this directory
with synthetic dense intervals.
